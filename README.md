# Ign
Building product UI for money — balances, transactions, and the screens that have to feel trustworthy.

I ship open finance kits under **bettdat llc**. Most dashboard repos on GitHub are one-off mocks. These two are meant to be reused.

## Featured

**[financehub-ui](https://github.com/Bettdatsh210-boop/financehub-ui)**  
React primitives and composed pages for a personal-finance dashboard: Money, StatCard, TransactionRow, Panel, AppShell. Tokenized CSS (no Tailwind).  
Live: [financehub-ui.netlify.app](https://financehub-ui.netlify.app)

**[financial-app-ui](https://github.com/Bettdatsh210-boop/financial-app-ui)**  
Full FinanceHub banking surface — React 18 + Tailwind. Balance cards, transaction history, responsive layout.  
Demo: [financial-app-ui-sigma.vercel.app](https://financial-app-ui-sigma.vercel.app)

## Stack

`React` `TypeScript` `JavaScript` `Vite` `Next.js` `Tailwind` `CSS tokens` `Netlify` `Vercel`
